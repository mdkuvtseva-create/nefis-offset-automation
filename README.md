# Автоматизация процесса зачета встречных требований (Нэфис Косметикс)

## О чём проект
Это учебный проект по оптимизации бизнес-процессов. В качестве кейса я разбирала процесс формирования и согласования соглашений о зачете встречных однородных требований (взаимозачетов) между компаниями. 
Изначально процесс был полностью ручным, занимал много времени и был подвержен ошибкам.

## Проблематика (AS-IS)
- Ручной поиск неоплаченных счетов-фактур.
- Долгий расчет сумм задолженности.
- Долгие согласования и высокий риск арифметических ошибок.
- Отсутствие единой системы контроля.

## Предложенное решение (TO-BE)
Я проанализировала рынок RPA-платформ и предложила два варианта автоматизации:
1. **Внедрение 1С:Предприятие 8** — настройка регламентных заданий, создание специализированного документа "Соглашение о зачете" и автоматизация сверки данных.
2. **Интеграция RPA-роботов (PIX Robotics)** — для автоматического ввода данных, работы с ЭДО (Диадок) и проверки условий зачета.

В рамках проекта я также составила план мероприятий, спроектировала бюджет изменений и оценила риски.

## Результаты (Ожидаемый эффект)
| Показатель | До | После |
| :--- | :--- | :--- |
| Время формирования соглашения | 30-60 мин | 2-5 мин |
| Поиск счетов-фактур | Вручную | Автоматически |
| Риск ошибок | Высокий | Минимальный |
